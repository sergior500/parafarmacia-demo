# Seguridad

La especificación vigente es [Arquitectura y controles de seguridad](./SEGURIDAD.md).

Ese documento describe el modelo de amenazas, autenticación y roles, CSRF,
limitación de frecuencia, validación de entradas, cabeceras, integración con
Shopify, webhooks, trazabilidad, gestión de secretos, respuesta ante incidentes
y la lista de apertura. También recoge expresamente los límites del sistema:
publicar una URL de API no concede permisos, pero ningún servicio conectado a
Internet puede prometer protección absoluta ni sustituir una prueba de
penetración independiente.
